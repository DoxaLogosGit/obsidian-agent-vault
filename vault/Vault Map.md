# Vault Map

Each top-level folder holds one kind of note. For a list of every note, open [[_meta/index|the master index]].

| Folder | What it holds |
|---|---|
| `Projects/` | Active work with a goal. One subfolder per project. |
| `Ideas/` | Early concepts that are not projects yet. |
| `Reference/` | General knowledge, how-tos, and setup notes. |
| `_sources/` | Raw inputs for ingest: chat exports, PDFs, articles. Never edited. |
| `_meta/` | Indexes, config, logs, and the schema. Agent-owned. |

To add a folder, create it and add its name to `_meta/vault-config.yml`.

# Example - Requirements

- Keep a list of plants, each with a last-watered date.
- A daily check flags each plant that is past its watering interval.
- Intervals differ per plant, from 3 to 10 days.
- A plain file is enough for storage at this size. ^[inferred]

See [[Example - Open Questions]] for what is not decided.
